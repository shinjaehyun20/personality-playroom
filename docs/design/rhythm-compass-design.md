# 선택코드 플레이룸 — 제품·디자인 계약

## 한 줄 가치
**16가지 중, 오늘 내 플레이 모드는?** 24개의 작은 선택을 통해 오늘의 4글자 코드와 한 장의 공유 카드를 만드는 비공식 놀이 경험.

## 문제와 수락 신호
- 문제: 성향 퀴즈는 시작 동기는 강하지만, 결과가 텍스트뿐이면 공유 순간의 감정과 대화가 끊긴다.
- 수락 신호: 3초 안에 퀴즈 목적과 시작 이유를 이해하고, 결과에서 자신의 코드·캐릭터·한 줄 훅이 담긴 PNG 카드를 공유할 수 있다.

## 제품 경계
- **포함:** 24문항, 4개 선호 축, 16가지 오늘의 코드, 캐릭터, 재미 미션, 결과 이미지 공유.
- **제외:** 공식 MBTI, 심리/의학적 진단, 희귀도·등수·통계, 능력·궁합·예측.
- **개인정보:** 로그인·추적·서버 저장 없음. 결과 계산은 브라우저 로컬에서만 수행.

## 카피 계층
1. 랜딩 훅: `16가지 중, 오늘 내 플레이 모드는?`
2. 약속: `24번의 선택으로 오늘의 4글자 코드를 만들어 보세요.`
3. 결과 주인공: 코드 → 결과명 → 한 줄 플레이 → 캐릭터
4. 공유 대화 유도: `너의 오늘의 플레이 모드는?`

## 결과 이미지 카드
- 캔버스: 1200×630 PNG. 코드·결과명·한 줄 훅·오늘의 미션·결과 캐릭터·비공식 고지를 포함.
- 지원 환경: Web Share Files로 PNG와 문구를 함께 공유.
- fallback: PNG 다운로드와 문구 복사. 지원하지 않는 환경에서도 결과가 사라지지 않아야 함.

## 시각 방향
- 오리지널 종이 질감의 여우·부엉이·고양이·곰 마스코트와 나침반 테이블.
- 크림 배경, 코랄/블루/옐로/바이올렛 역할색, 높은 잉크색 대비.
- 결과 아트는 portrait/square 혼재 원본을 `object-fit: cover`로 안전하게 표시하고, 카드 생성은 contain 비율로 핵심이 잘리지 않게 한다.

## 공개면 게이트
- canonical, title, description, Open Graph/X Card, 이미지 크기·alt, robots, sitemap, WebApplication JSON-LD.
- JSON-LD와 메타데이터는 경험 범위를 과장하지 않고 비공식 놀이 퀴즈임을 유지한다.
- 실제 배포 후 원격 HTML·robots·sitemap·OG 이미지 URL을 다시 읽어야 한다.

## 수락 기준
- 시작 → 24개 선택 → 코드/이름/축/미션 → 이미지 공유 → 재시작이 동작한다.
- 320px에서 가로 스크롤이 없고, 버튼/키보드 포커스가 확인된다.
- 16개 어느 결과에서도 이미지 카드에 코드·결과명·한 줄 훅·해당 캐릭터가 들어간다.
- 공개 메타와 결과 문구에 진단·희귀도·심리 권위 주장이 없다.
