# ADR 0001 — translate, do not clone

**Decision:** use only observed high-level funnel patterns from the public reference: centered introductory moment, illustration-led calm atmosphere, short sequential choices, result reveal. Build an original work-rhythm reflection experience instead.

**Rejected:** MBTI vocabulary, personality taxonomy, type counts, rarity/ranking, character line-up, brand copy, proof counters, visual assets and psychological authority language.

**Why:** the reference is a discovery source, not an implementation source. The MVP must be honest about its entertainment/reflection boundary and visually distinct.

**Verification:** compare browser screenshot and copy against the reference observation; ensure no forbidden terms/brands are present in source.
