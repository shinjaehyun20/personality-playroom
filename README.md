# 선택코드 플레이룸

8개의 상황 선택으로 만드는 **오늘의 4글자 선택 코드**. MBTI를 떠올리게 하는 4개 축(E/I, S/N, T/F, J/P)을 사용하지만, 공식 MBTI 검사·심리 진단·의학적 평가가 아닌 **재미를 위한 비공식 심리 퀴즈**입니다.

## Run
`index.html`을 최신 브라우저로 여세요. 의존성, 로그인, 추적, 서버가 없습니다.

## Flow
1. 8개 일상 상황 선택
2. 에너지·관찰·결정·생활의 4개 축을 로컬 계산
3. 16개 중 하나의 오늘의 선택 코드와 캐릭터 이름·작은 재미 미션 표시
4. 재시작 시 선택값을 모두 초기화

## Originality / safety
- 원래 X 레퍼런스에서는 짧은 퀴즈 퍼널과 히어로 중심 구도만 연구했습니다.
- 브랜드, 문구, 희귀도/순위 주장, 캐릭터, 외부 자산은 사용하지 않았습니다.
- `assets/personality-playroom-hero.png`은 이 프로젝트를 위해 생성한 오리지널 마스코트 일러스트입니다.
- 결과는 고정 성격·능력·건강을 판단하지 않으며, 언제든 달라질 수 있는 놀이용 코드입니다.

## Files
- `index.html` — 전체 앱
- `assets/personality-playroom-hero.png` — 오리지널 4마스코트 히어로
- `docs/design/rhythm-compass-design.md` — UI/UX 방향 및 검증 기준
- `manifest.json` — 파일 해시 및 원본 메타데이터
